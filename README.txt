TORRES & CO. — ZIP para Vercel

Incluye una tienda negra/dorada y un importador que intenta recuperar productos, precios, descripciones e imagen principal desde el catálogo público de Fausto Relojes al compilar.

Precio aplicado: precio original × 2 + $20.000.
Ejemplos de respaldo incluidos: Patek P Piedras, Royal Pop, modelos 433/434 de acero, RM 2000, C14 y Tomi Cuero 988.

Importante: la descarga automática depende de que el sitio de origen permita el acceso al momento del deploy. El ZIP trae una muestra de respaldo; no puedo asegurar que el importador consiga absolutamente todas las fotos/productos. Revisá el sitio antes de vender.

Subida: descomprimí, subí a GitHub, importá en Vercel. Build Command: npm run build; Output Directory: public; Install Command: npm install.
